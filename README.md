# Claude Usage Trend Tracker

A macOS menu bar app that shows your Claude Code plan usage, projects whether your pace will exhaust a limit before it resets, and notifies you.

- Install and first-launch notes: `docs/install.md`
- Release packaging (local build, DMG, Mac App Store): `docs/release.md`
- Privacy policy: `docs/privacy.md`
- Support: open an issue in this repository.

Build and install with `scripts/build-local.sh`.
